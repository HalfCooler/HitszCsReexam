面向准备参加哈尔滨工业大学（深圳）081200 计算机科学与技术预推免复试的同学，一起把零散的机考资料整理成能检索、能练习、能复盘的题库。

> 项目处于 MVP 阶段：已有题库浏览、单题练习、本机错题本和模拟考试；GitHub 登录及跨设备同步仍在开发中。

## 预推免机考都考什么

HITSZ 计算机科学与技术学院在可观测的某些年前筹备了一套机考题库，主要考察以下知识点：

- C 语言程序设计
- 数据库系统
- 数据结构
- 离散数学
- 计算机网络
- 操作系统

机考就是你需要在 100 分钟内，完成 2 分每道的 65 道单选和 1 分每道的 20 道判断题，满分 150 分，70 分及格。题型恒定不变，题目从大题库中 **完全随机** 抽取，单批次同学的试题完全相同，但题目和选项顺序不完全（完全不）一致。

所以在本系统中，并没有所谓的历年真题和预测，只有梳理下来的题库。

正式推免机试使用 2016 HIT SSE 作业与考试系统，本系统模拟考试部分将尽量贴近原平台界面。

## 在这个系统能做什么

从找到一道题，到弄懂一道题，再到完成一次模拟考试（或者只想像考科目一那样过了就行），都能在这里完成：

- **浏览与搜索题库**：按题型和知识点查找试题，也能用关键词搜索。
- **随机刷题**：从题库抽取题目，逐题提交并查看参考答案与解析。
- **错题本**：在当前浏览器保存答错的题目，重新答对后自动移出。
- **模拟考试**：随机抽取 65 道单选和 20 道判断，限时 100 分钟，交卷后查看成绩和逐题解析。
- **GitHub 登录**：计划用于跨设备保存练习记录，目前尚未实现。

计划使用 **Blazor + .NET 10** 开发（由于作者熟悉这套框架），方便持续维护和迭代。

| --- | --- |

| [`src/data/answers/answer.json`](src/data/answers/answer.json) | 应用读取的题库，包含题目、附加内容、复合选择、答案与解析 |

现有答案解析并非考试平台公布的官方答案。部分题目存在题面缺失或口径歧义，使用时请结合解析中的说明自行核对。

练习记录保存在当前浏览器的本机存储中，清除浏览器数据后会丢失；模拟考试过程只保留在当前页面，刷新会结束本次考试。没有确定参考答案的题目可在单题练习中查看解析，但不会计入成绩，也不会进入模拟考试。

## 本地运行

需要安装 .NET 10 SDK。在仓库根目录执行：

```bash
dotnet run --project src/HitszCsReexam.Web
```

启动后打开终端显示的本地地址。应用从 `src/data/answers/answer.json` 读取题库，构建时会复制到应用输出目录。

## 开发计划

### 前端精简方案（2026-10-04）

目标是用早期 HTML 文档的组织方式构建复习工具：普通标题、文本链接、原生表单控件、列表与细分隔线。界面保持紧凑、可读和可操作；不采用 Win9x 窗口、立体边框、像素字体、复古图标等装饰，也不沿用 `todo_simulate_exam.html` 的视觉样式。

实施顺序：

1. **全局与首页**：将侧栏、顶栏合并为文本导航；首页只保留功能入口、题库统计和必要说明。删除宣传文案、插画、功能卡片、英文眉题与开发中占位。
2. **题库**：搜索、题型筛选、答案显示放在同一工具栏；题目按文档流排列，用分隔线区分。保留关键词搜索、加载更多、答案解析和直接练习入口。
3. **练习与错题**：使用原生单选框与关联标签；精简页头和重复导航，将题号、状态、作答统计压缩为普通文本。保留提交、跳过、结果解析与本机错题记录。
4. **模拟考试**：保留题目与答题卡分栏；时间、作答数量和交卷操作集中在工具栏。考试开始后收起介绍；交卷后在原区域展示成绩和解析。
5. **样式与检查**：重写现有样式而非追加覆盖，删除网络界面字体、阴影、渐变和动画。保留代码字体、Markdown 图片/表格/代码与数学排版；检查桌面、窄屏及主要操作流程。

范围：本轮调整展示与控件，不改变题库、组卷、计时、判分、错题存储及不确定答案不判分的规则。考试刷新恢复与跨设备同步仍按后续计划处理。

验收：桌面首屏能显示普通短题的题干、全部选项和提交按钮；首页入口直接可见；窄屏工具栏可换行、考试分栏可纵向排列；键盘可操作，题目中的代码、公式、图片和表格仍可阅读。如本地编译或端口受 `dotnet watch` 影响，停止重复编译并说明情况。

本轮已实施上述展示调整。通过现有本地服务检查了首页、题库搜索/筛选/答案开关、练习提交、错题加入与移出、考试跳题保留答案、键盘单选、交卷确认及成绩解析；检查了代码、附图、表格、公式和 390px 窄屏排版。`git diff --check` 通过。一次编译因运行中的 `HitszCsReexam.Web` 占用输出文件失败，未重试或停止该进程；后续的判断选项去重和重连提示调整尚未验证运行效果。
